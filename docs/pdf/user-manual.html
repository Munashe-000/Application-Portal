User Guide

1. Introduction

The Application Portal is used by applicants to submit programme applications and by internal review staff to manage evaluation, ranking, and final decisions. The system is designed so that each user sees only the information needed for their role.

Applicant Users

Applicants complete the online form, upload required documents, and respond to programme communications.

Staff Users

Staff members review essays, scores, documents, interviews, and final outcomes according to their assigned permissions.

2. Logging In

  1. Open the portal in a secure browser session.
  2. Enter your email address and password.
  3. Select the sign-in button.
  4. If prompted, complete any additional verification step configured for your account.

3. Applicant Instructions

3.1 Starting an Application

  1. Open the applicant portal.
  2. Review the eligibility questions carefully.
  3. Select an answer for each question.
  4. Select Continue to move forward.

If any eligibility answer is not accepted by programme rules, the application cannot continue. A reference number may still be created for internal reporting.

3.2 Consent and Personal Information

  • Read the consent statements before submitting personal information.
  • Confirm that you understand how your data will be used for the application process.
  • Proceed only if you agree to the stated conditions.

3.3 Required Documents

Applicants should prepare the following before submission:

  • transcript
  • TEFL certificate
  • passport or ID card
  • reference letters
  • curriculum vitae or resume

4. Staff Dashboard Instructions

4.1 Dashboard Layout

The staff dashboard is organized into three working areas:

  • Applications list
  • Application details panel
  • Recent activity or audit panel

4.2 Role-Specific Use

5. Master Scorecard

The score summary helps authorized staff compare applicants by combining profile-based points and review-stage scores.

5.1 Typical Score Elements

  • teaching experience points
  • TEFL certification points
  • degree points
  • essay score
  • interview score

5.2 Using the Scorecard

  1. Open the score summary page or dashboard area.
  2. Review the ranked list of applicants.
  3. Use filters to narrow the list where needed.
  4. Export to spreadsheet if an offline review pack is required.

6. Privacy and Security Reminders

  • Do not share accounts or passwords.
  • Access only the records required for your role.
  • Sign out after use, especially on shared devices.
  • Report any suspected data issue immediately.

7. Support and Common Questions

7.1 Common Applicant Questions

QuestionGuidance
Why can I not continue after the first questions?One or more eligibility answers does not meet the programme rules.
What documents are required?Check the document list in the applicant portal before submission.
Can I request a copy of my information?Yes. A data export process should be available according to the platform policy.

7.2 Common Staff Questions

QuestionGuidance
Why is a stage action disabled?The application has not yet met the prerequisites for that step.
Why can I not see another reviewer’s score?Reviewer separation rules hide peer scores until authorized senior stages.
Can I download multiple documents together?Yes. The full solution should support zipped multi-document download for authorized admins.
