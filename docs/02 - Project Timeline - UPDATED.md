# Project Timeline

**Project:** Application Portal  
**Delivery Window:** 10 - 12 Weeks (Recommended)  
**Team:** 3 Developers  
**Date:** 12 May 2026  

---

## 1. Schedule Overview

Applications typically open **mid-September**. Admin training and the final technical handover should happen **before** that opening window.

Given the multi-role, multi-stage workflow and POPIA technical controls required from day one, a realistic delivery plan is **10 to 12 weeks** with a team of three experienced developers working in parallel.

| Phase | Timeline | Primary Goal |
| :--- | :--- | :--- |
| **Phase 1: Setup & Alignment** | Weeks 1 - 2 | Environment provisioning, workflow mapping, architecture lock. |
| **Phase 2: Core Build** | Weeks 3 - 8 | Applicant portal + staff workflows built in parallel. |
| **Phase 3: Compliance & Hardening** | Weeks 9 - 10 | Audit logging, exports/deletion, security review, client UAT. |
| **Phase 4: Handover & Training** | Weeks 11 - 12 | Production deployment, documentation, and admin/staff training. |

---

## 2. Weekly Milestones

| Week | Deliverable / Milestone |
| :--- | :--- |
| **Week 1** | Discovery, workflow confirmation, POPIA baseline, initial schema draft. |
| **Week 2** | Hosting setup, identity/RBAC, eligibility gate, consent capture, audit log skeleton. |
| **Week 3** | Applicant registration + core form + mandatory document upload rules. |
| **Week 4** | Staff dashboard foundation + role scoping + essay review module (isolated view). |
| **Week 5** | Academic scoring sheets + per-subject grades + computed averages (audited). |
| **Week 6** | Document verification checklist + mandatory doc enforcement + issue notes. |
| **Week 7** | Master scorecard (ranking/filter/export) + shortlisting stage enforcement. |
| **Week 8** | Interview scoring sheets + final decision stage + notification email flows. |
| **Week 9** | Data export (ZIP) + deletion/retention utilities + audit trail hardening. |
| **Week 10** | End-to-end testing, security review, performance smoke testing, client UAT. |
| **Week 11** | Production deployment + monitoring/alerts + operational runbook. |
| **Week 12** | Admin training + handover pack + final sign-off buffer. |

---

## 3. Development Streams

* **Stream 1 (Lead):** Core API, database integrity, POPIA safeguards, infrastructure.
* **Stream 2 (Frontend):** Applicant portal UX, responsive forms, uploads, email templates.
* **Stream 3 (Workflow):** Staff scoring tools, scorecard/ranking, admin dashboards, exports.

---

## 4. Suggested Calendar Target (to meet mid-September opening)

If kickoff begins by **Monday, 8 June 2026**, a 12-week plan completes by **Friday, 28 August 2026**, leaving early September for final admin orientation and contingency before applicants arrive **mid-September 2026**.
