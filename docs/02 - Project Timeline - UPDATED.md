# Project Timeline

**Project:** Application Portal  
**Delivery Window:** 8 - 10 Weeks  
**Team:** 3 Developers  
**Date:** 5 May 2026  

---

## 1. Schedule Overview

The delivery is scheduled for 8 to 10 weeks. By utilizing three developers, we can run the foundation, applicant, and staff workstreams in parallel to meet this window without compromising on the security or testing phases.

| Phase | Timeline | Primary Goal |
| :--- | :--- | :--- |
| **Phase 1: Setup** | Week 1 | Environment provisioning and architecture lock. |
| **Phase 2: Build** | Weeks 2 - 7 | Concurrent development of all core modules. |
| **Phase 3: Testing** | Week 8 | Security hardening, bug fixing, and client UAT. |
| **Phase 4: Launch** | Weeks 9 - 10 | Production deployment and technical handover. |

---

## 2. Weekly Milestones

| Week | Deliverable / Milestone |
| :--- | :--- |
| **Week 1** | Schema design, hosting setup, and identity/role model. |
| **Week 2** | Applicant registration, POPIA consent flow, and eligibility check. |
| **Week 3** | Core application forms and document upload validation. |
| **Week 4** | Staff dashboard layout and essay review workflow. |
| **Week 5** | Academic scoring module and document verification tools. |
| **Week 6** | Ranking dashboard, master scorecard, and shortlist logic. |
| **Week 7** | Interview sheets, final decision flow, and audit logging. |
| **Week 8** | Full system testing, security audit, and UAT sign-off. |
| **Week 9** | Production deployment and data migration preparation. |
| **Week 10** | Final handover, documentation, and staff training. |

---

## 3. Development Streams

*   **Stream 1 (Lead):** Core API, database integrity, POPIA safeguards, and infrastructure.
*   **Stream 2 (Frontend):** Applicant portal, responsive forms, and file management.
*   **Stream 3 (Workflow):** Staff reviewer tools, scoring engines, and admin dashboards.
