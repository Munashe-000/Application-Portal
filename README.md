# Application-Portal

Demo portal and proposal pack for a multi-role, multi-stage South African application system with POPIA-focused controls.

## Files

- `index.html` - stakeholder demo UI
- `styles.css` - conservative university-portal styling
- `app.js` - seeded workflow, role views, and scorecard logic
- `docs/proposal.md` - architecture, stack, compliance, and delivery proposal
- `docs/cost-estimate.md` - AWS hosting and seasonal operating estimate
- `docs/demo-script.md` - suggested walkthrough for stakeholder presentations

## Run

Open `index.html` in a browser.
